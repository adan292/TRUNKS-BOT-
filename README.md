# ⚡ Trunks-bot

Bot de WhatsApp multi-dispositivo inspirado en Trunks de Dragon Ball Z.
Vengo del futuro para administrar tu grupo 💪

## 📌 Características
- **Administración**: Kick, ban, promover, demote, bienvenidas
- **Anti-Spam/Anti-link**: Protección automática de grupos
- **Descargas**: YouTube, TikTok, Instagram, Spotify
- **Diversión**: Stickers, IA, juegos, frases de Trunks
- **Tecnología**: Baileys + TypeScript + Node.js

## 🚀 Instalación en HidenCloud

1. Clona el repo: `git clone https://github.com/tuusuario/Trunks-bot`
2. Entra: `cd Trunks-bot`
3. Instala: `npm install`
4. Ejecuta: `npm start` o `npm run dev`

## ⚙️ Configuración
Edita el archivo `.env` con tu número y nombre del bot.

## 📜 Comandos
Escribe `.menu` en el bot para ver todos los comandos.
